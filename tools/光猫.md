# 光猫更换

中兴 `ZXHN F7015TV3`  型号光猫更换。

GPON 和 EPON 是什么？问了下必应的 AI 回答如下：

> GPON 和 EPON 是两种主流的光纤接入技术。
>
> **GPON** 是电信领域（ITU-T标准）的产物，追求更高的带宽和效率，技术更复杂，成本也略高；而**EPON** 是以太网领域（IEEE标准）的延伸，强调与现有以太网设备的简单兼容和低成本。
>
> **GPON**： 下行2.5G，上行1.25G的**不对称**设计非常符合用户下载多、上传少的实际需求。采用NRZ编码，效率更高。
>
> **EPON**： 上下行对称1.25G，但由于使用了8B/10B编码（每8bit数据用10bit传输），实际有效带宽只有1G。

这款光猫是双模的，两种模式都支持，一般会自动切换，也可以在设置里手动更改。

## 开始更换光猫

参考更换移动千兆宽带，更换光猫其实不难，一共大致分为以下三步：

- 备份原光猫信息（需要获取光猫超级管理员密码）
- 认证光猫（LOID，移动也叫做 PASSWORD）
- 光猫设置上网（桥接或路由）

### 常用命令

```bash
setmac show2     查看系统参数

setmac 1 修改 2查看 3删除
setmac 1 [ID] [内容]

setmac 1 32769   修改光猫的 MAC 地址（可选），列如格式是：setmac 1 32769 B4:BA:12:B8:EE:50
setmac 1 2176    gponSN 前 4 位
setmac 1 2177    gponSN 后 8 位
setmac 1 768     设备标识码前 6 位数字（可选）
setmac 1 512     设备标识码后 17 位数字（可选）
setmac 1 2180 LOID      （与2179不同时改）
setmac 1 2179 password  （与2180不同时改）
```

另外，没必要改地区，除非你想被运营商管控。

#### 修改命令

```bash
# 修改 LOID 码 （重启 reboot，看注册是否成功，若失败在改下面的 SN 或设备标识号）
setmac 1 2179 7597xxxxx

# 重启
reboot

# 修改 SN 码（可选） 注册 LOID 失败可改
# 设备标识号 : SCTY1916281C
setmac 1 2176 SCTY
setmac 1 2177 1916281C

# 修改设备标识号（可选）
# 设备型号: TEWA-7100A
setmac 1 768 TEWA
setmac 1 512 7100A
```

### 修改区域

查看所有地区： `/etc/init.d/regioncode`   ，会出现各省的拼音和代号

 改地区：`upgradetest sdefconf xxx`

注意：更改地址 telnet 固化可能会丢失。

### 劫持 ITMS

由于中兴光猫会劫持 ITMS，劫持 ITMS 注册（破解刷电信后打开任意网页自动跳转 LOID 注册页面）

```bash
sendcmd 1 DB set PDTCTUSERINFO 0 Status 0
sendcmd 1 DB set PDTCTUSERINFO 0 Result 1
sendcmd 1 DB save
```
